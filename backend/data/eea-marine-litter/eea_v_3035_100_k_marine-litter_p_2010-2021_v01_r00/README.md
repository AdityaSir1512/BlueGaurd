# Assessment of marine litter in all four regional seas, 2010-2021

This is the metadata for the data showing the results of a preliminary classification and identification of ‘non-problem areas’ and ‘potential problem areas’ with respect to marine litter in Europe’s Seas, using the prototype Marine Litter Assessment Tool (MALT), a multi-metric indicator-based status assessment tool. Please see the European Topic Centre (ETC) report "Marine Litter in Europe - An integrated assessment from source to sea" (2022).https://sdi.eea.europa.eu/geonetwork/srv/api/records/15389e51-5204-4c6b-b40f-ad4af9a6f590
